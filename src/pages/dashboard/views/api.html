LocalShare REST API

Integrate or script file transfers using standard HTTP endpoints.

Local Network Only
GET /api/shared-file List all files currently shared by the PC 
curl http://localhost:5199/api/shared-file
POST /api/upload Upload files to PC (multipart/form-data) 
curl -F "files=@photo.jpg" http://localhost:5199/api/upload
GET /download/:id Download a file by its ID 
curl -O http://localhost:5199/download/0
POST /api/clipboard Send text to host PC clipboard (instantly paste with Ctrl+V) 
curl -X POST -H "Content-Type: application/json" -d '{"text":"Hello from phone!"}' http://localhost:5199/api/clipboard
GET /api/server-info Get host computer name, platform, and port 
curl http://localhost:5199/api/server-info
