Device Server API Spec

Expected JSON formats for pairing with LocalShare
HTTP GET /?key=<6-digit>&pc=<hostname>

LocalShare desktop polls your mobile server every 1 second. Send the header X-Pairing-Key: <6-digit> and query param ?key=....

1. Success Response (Key Accepted) • 200 OK 
{
  "success": true,
  "status": "connected",
  "deviceName": "My Phone",
  "message": "Device paired successfully"
}
2. Pending Response (Waiting for Key) • 202 or 200 
{
  "success": false,
  "status": "pending",
  "message": "Waiting for key entry on phone"
}
Once your server returns "success": true, LocalShare instantly connects your device.
