Device Server API Spec

Tasker endpoints on port 8000 for LocalShare
HTTP GET :8000/alive & :8000/pair?key=<6-digit>&pc=<hostname>

Discovery probes GET /alive on your LAN subnet. First pairing polls GET /pair?key=...&pc=... (plus X-Pairing-Key header) every 1 second for up to 60 seconds.

1. Discovery & Status (GET /alive) • 200 OK 
{
  "phoneModel": "CPH2487",
  "batteryLevel": 81,
  "mode": "General",
  "deviceId": "dev_optional_stable_id"
}
2. Pair Accepted (GET /pair) • 200 OK 
{
  "success": true,
  "status": "connected",
  "phoneModel": "CPH2487",
  "batteryLevel": 81,
  "mode": "General",
  "message": "Device paired successfully"
}
3. Pending Confirmation • 202 Accepted 
{
  "success": false,
  "status": "pending",
  "message": "Waiting for confirmation on phone"
}
4. Denied on Phone • 403 Forbidden 
{
  "success": false,
  "status": "denied",
  "message": "Pairing cancelled on phone"
}
Returning HTTP 403 or "status": "denied" stops PC polling immediately.
